# {{ cookiecutter.repo_name }}

{{ cookiecutter.description }}

This repo holds [OpenTofu](https://opentofu.org) modules under
`{{ cookiecutter.modules_dir }}/`, plus `mise run` tasks to scaffold, test,
plan, and apply any one of them.

## Getting Started

Install [mise](https://mise.jdx.dev), which manages every tool this repo
uses. If you already have any of the tools in `mise.toml` installed another
way, uninstall them and let mise manage them, to avoid version conflicts.

```shell
git clone <repo-url>
cd {{ cookiecutter.repo_slug }}
mise install
pre-commit install
```

With the hooks installed, `tofu fmt`, `tofu validate`, tflint, trivy,
terraform-docs, and shellcheck run on every commit. Run them against all
files with `pre-commit run -a`.

## Commands

Each task targets one module by its path relative to
`{{ cookiecutter.modules_dir }}/` (e.g. `network/hub`). Run a task with no
arguments to print its usage and the current list of modules.

<!-- markdownlint-disable MD013 -->
| Command | Description |
| ------- | ----------- |
| `mise run new-module <root\|shared> [-o <dir>]` | Scaffold a root or shared module into `<dir>` (default `{{ cookiecutter.modules_dir }}/`) |
| `mise run test <module> \| --all` | Run `tofu fmt`, `tofu validate`, tflint, trivy, and `tofu test` |
| `mise run plan <module> \| --all` | Run `tofu plan` for a root module |
| `mise run apply <module>` | Run `tofu apply` for one root module (no `--all`, on purpose) |
| `mise run break-lease <module> \| --all` | Break a stuck azurerm state lease |
<!-- markdownlint-enable MD013 -->

## Modules

Modules live under `{{ cookiecutter.modules_dir }}/` at any depth and are
found by convention, so there's no list to update when you add, move, or
delete one. See
[{{ cookiecutter.modules_dir }}/README.md](./{{ cookiecutter.modules_dir }}/README.md).

The directory is set by `MODULES_DIR` in `mise-tasks/lib/common.sh`. Every
task reads it, so change it there (and move the directory) if modules should
live elsewhere.

Each module's `README.md` is generated by terraform-docs from its
`.header.md` and `.tf` files. Don't edit it by hand.

### Adding a module

```shell
mise run new-module root
mise run new-module shared -o {{ cookiecutter.modules_dir }}/network
```

The first creates `{{ cookiecutter.modules_dir }}/<slug>`, the second
`{{ cookiecutter.modules_dir }}/network/<slug>`. `-o` is relative to the repo
root. A module created outside `{{ cookiecutter.modules_dir }}/` won't be
found by the other tasks.

This runs the `root-module` or `shared-module` template from
[JoshSLawrence/cookiecutter](https://github.com/JoshSLawrence/cookiecutter).
It prompts for the module name and which providers to use, and defaults to
this repo's OpenTofu version. For a root module, configure remote state in
its `backend.tf` before the first apply.

### OpenTofu version

The root `mise.toml` pins the OpenTofu version used by the pre-commit hooks,
and new modules default to it. Each module pins its own version in its
`mise.toml`, and the `mise run` tasks use that one. When raising the root pin,
check that every module's `required_version` still allows it.
