# Root Module Template

Scaffolds a new [OpenTofu](https://opentofu.org) root module (a configuration
you run `tofu plan` / `tofu apply` against), with linting, security scanning,
and doc generation pre-configured.

## Requirements

- [cookiecutter](https://cookiecutter.readthedocs.io) 2.2+
- [mise](https://mise.jdx.dev)

## Usage

Run from the directory that should contain the new module:

```bash
cookiecutter gh:JoshSLawrence/cookiecutter --directory templates/root-module
```

In a repo generated from [iac-repo](../iac-repo/README.md), run
`mise run new-module root [-o <dir>]` instead. It creates the module in the
repo's modules directory (default `iac/`) or `<dir>`, and defaults to the
repo's OpenTofu version.

## Inputs

<!-- markdownlint-disable MD013 -->
| Input | Description | Default |
| ----- | ----------- | ------- |
| `module_name` | Display name, used as the README title | `Example` |
| `module_slug` | Directory name and suggested state key | derived from `module_name` |
| `description` | Short description for the README | `Example OpenTofu root module` |
| `opentofu_version` | Pinned in `mise.toml` and required as `>=` in `terraform.tf` | `1.9.0` |
| `use_azurerm` | Declare and configure `hashicorp/azurerm`, and enable the tflint azurerm ruleset | `yes` |
| `use_azapi` | Declare and configure `azure/azapi` | `no` |
| `use_azuread` | Declare and configure `hashicorp/azuread` | `no` |
| `use_random` | Declare `hashicorp/random` | `no` |
<!-- markdownlint-enable MD013 -->

Each selected provider is declared as `~> <major>.<minor>` of the pinned
version, and the exact versions are recorded in `.terraform.lock.hcl`.
Provider and tool versions are hardcoded in `cookiecutter.json` — see the
root [README](../../README.md#updating-versions).

## Generated Structure

```text
<module_slug>/
├── .header.md             # README preamble
├── .terraform-docs.yaml
├── .terraform.lock.hcl    # created by tofu init; commit it
├── .tflint.hcl
├── backend.tf             # commented-out azurerm backend example
├── main.tf
├── mise.toml              # pins opentofu, terraform-docs, tflint, trivy
├── modules/
├── outputs.tf
├── providers.tf           # provider blocks for the selected providers
├── README.md              # generated by terraform-docs
├── scripts/
├── terraform.tf           # required_version + selected providers
├── tests/
├── trivy.yaml
└── variables.tf
```

The placeholder directories each hold a `README.md` explaining what goes
there. Delete them once real content has been added.

The template doesn't create a `.gitignore`, `.pre-commit-config.yaml`, or git
repo, because the containing repo provides those.

## Post-Generation

The post-generation hook:

1. Installs the tools pinned in `mise.toml`. It only installs those tools, not
   everything in your global mise config.
1. Runs `tofu init -backend=false` and `tofu fmt`.
1. Generates `README.md` with terraform-docs.
