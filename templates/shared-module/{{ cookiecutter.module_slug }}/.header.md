## Usage

Reference this module from a root (or child) module, pinned to a released, module-scoped tag:

```hcl
module "{{ cookiecutter.module_slug }}" {
  source = "git::https://github.com/JoshSLawrence/shared-modules.git//modules/{{ cookiecutter.module_slug }}?ref={{ cookiecutter.module_slug }}/vX.Y.Z"

  # module inputs...
}
```

Or over SSH:

```hcl
module "{{ cookiecutter.module_slug }}" {
  source = "git::ssh://git@github.com/JoshSLawrence/shared-modules.git//modules/{{ cookiecutter.module_slug }}?ref={{ cookiecutter.module_slug }}/vX.Y.Z"

  # module inputs...
}
```

Always pin `ref` to a released tag — see [Versioning and Releases](../../CONTRIBUTING.md#versioning-and-releases) — rather than a branch. Released versions of this module are listed on the repo's [Releases](https://github.com/JoshSLawrence/shared-modules/releases) page as `{{ cookiecutter.module_slug }}/vX.Y.Z`.

See [CHANGELOG.md](./CHANGELOG.md) for version history and upgrade notes.
