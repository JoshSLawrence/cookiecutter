# Shared Module Template

Scaffolds a new [OpenTofu](https://opentofu.org) shared module for the
[shared-modules](https://github.com/JoshSLawrence/shared-modules) repo, with
linting, security scanning, and doc generation pre-configured.

A shared module is consumed by other modules, so the generated module
declares `required_providers` but never configures a `provider` block or a
backend — that's the caller's job.

## Requirements

- [cookiecutter](https://cookiecutter.readthedocs.io) 2.2+
- [mise](https://mise.jdx.dev)

## Usage

Run from the root of your shared-modules clone, so the module lands under
`modules/`:

```bash
cookiecutter gh:JoshSLawrence/cookiecutter \
    --directory templates/shared-module -o modules
```

shared-modules also includes this repo as a submodule, and
`mise run new-module` there runs this template with the repo's OpenTofu floor
as the default. In a repo generated from [iac-repo](../iac-repo/README.md),
`mise run new-module shared [-o <dir>]` creates the module in the repo's
modules directory (default `iac/`) or `<dir>`.

The generated `.header.md` documents consumption from the shared-modules
repo (`git::https://github.com/JoshSLawrence/shared-modules.git//modules/...`).
Edit it if the module lives elsewhere.

## Inputs

<!-- markdownlint-disable MD013 -->
| Input | Description | Default |
| ----- | ----------- | ------- |
| `module_name` | Display name, used as the README title | `Example` |
| `module_slug` | Directory name and release tag prefix (`<slug>/vX.Y.Z`) | derived from `module_name` |
| `description` | Short description for the README | `Example OpenTofu shared module` |
| `opentofu_version` | Pinned in `mise.toml` and required as `>=` in `terraform.tf` | `1.9.0` |
| `use_azurerm` | Declare `hashicorp/azurerm` and enable the tflint azurerm ruleset | `yes` |
| `use_azapi` | Declare `azure/azapi` | `no` |
| `use_azuread` | Declare `hashicorp/azuread` | `no` |
| `use_random` | Declare `hashicorp/random` | `no` |
<!-- markdownlint-enable MD013 -->

Each selected provider is declared as `>= <pinned version>`, so callers can
use newer releases. Provider and tool versions are hardcoded in
`cookiecutter.json`. See the root
[README](../../README.md#updating-versions).

## Generated Structure

```text
<module_slug>/
├── .header.md             # README preamble with the module's git source
├── .terraform-docs.yaml
├── .tflint.hcl
├── CHANGELOG.md
├── examples/
├── main.tf
├── mise.toml              # pins opentofu, terraform-docs, tflint, trivy
├── modules/
├── outputs.tf
├── README.md              # generated by terraform-docs
├── scripts/
├── terraform.tf           # required_version + selected providers
├── tests/
├── trivy.yaml
├── variables.tf
└── VERSION                # v0.0.1
```

The placeholder directories each hold a `README.md` explaining what goes
there. Delete them once real content has been added.

The template doesn't create a `.gitignore`, `.pre-commit-config.yaml`, or git
repo, because the containing repo provides those.

## Post-Generation

The post-generation hook:

1. Installs the tools pinned in `mise.toml`. It only installs those tools, not
   everything in your global mise config.
1. Runs `tofu init -backend=false` and `tofu fmt`.
1. Generates `README.md` with terraform-docs.
